## How to Save and Use These Files on Your Laptop

1. **Copy or Download:**
   - In your code workspace, simply copy the `brand_and_media_kit/` folder to your local desktop or project directory.
   - Alternatively, open the files located under `/public/brand_and_media_kit/` in any web browser.

2. **Vector Logos (.SVG):**
   - SVGs are vector graphics that scale infinitely without pixelation.
   - Open them directly in Adobe Illustrator, Inkscape, Figma, Canva, CorelDraw, or any web browser.
   - Import them directly into PowerPoint presentations, Microsoft Word letterheads, or website templates.

3. **Brochures, Posters, and Fliers (.HTML):**
   - Each collateral file is 100% self-contained with embedded fonts, CSS, and vector graphics.
   - Double-click any `.html` file to open it in Chrome, Safari, Edge, or Firefox.
   - Click the **Print / Save as PDF** button at the top of the page (or press `Ctrl+P` / `Cmd+P`), choose **Save as PDF**, and select standard paper size (A4 / A5 / Landscape).
   - Send the resulting high-resolution PDF directly to commercial printers.

4. **Corporate Email Signature:**
   - Open `corporate-email-signature.html` in your browser.
   - Select the signature with your cursor, copy (`Cmd+C` / `Ctrl+C`), and paste directly into your email client settings.
